# 생활관 홈페이지 (공개 화면 + 관리자)

대학교 생활관 홈페이지 형식(상단 GNB 메가메뉴 · 메인 비주얼 · 퀵메뉴 · 게시판 탭 · 오늘의 식단 · 일정 · 알림존 · 레이어 팝업 · 서브페이지 LNB)을 따른 **서버 없는 정적 홈페이지**입니다.

| 주소 | 용도 |
|---|---|
| `index.html` | 공개 홈페이지 (학생·방문자용) |
| `admin.html` | 관리자 페이지 (내용 수정·게시글 작성·식단 입력) |
| `manual.html` | 관리자 사용 매뉴얼 (사진 올리기·용량 안내 포함) |

## 바로 열어보기 (설치·로그인 없음)

압축을 풀고 **`index.html`을 더블클릭**하면 홈페이지, **`admin.html`을 더블클릭**하면 관리자 페이지가 열립니다. 웹서버도, GitHub 연결도 필요 없습니다.

관리자 페이지는 기본이 **로컬 편집 모드**입니다.
1. 왼쪽 메뉴에서 내용을 수정합니다. 수정 내용은 이 브라우저에 자동 보관되어 창을 닫았다 열어도 남아 있습니다.
2. **미리보기**로 홈페이지에 어떻게 보이는지 확인합니다.
3. **파일 내려받기**를 누르면 `site.js` · `posts.js` · `meals.js`가 내려받아집니다. 이 파일을 사이트의 `data` 폴더에 덮어쓰면 홈페이지에 반영됩니다.
4. 사진·첨부파일은 관리자의 [업로드]·[이미지] 버튼으로 고르면 자동으로 줄인 파일이 내려받아지고 주소가 채워집니다. 그 파일을 `uploads` 폴더에 올리면 됩니다.

## 유지 비용: 0원

- **서버·DB 없음**: HTML·CSS·JS 파일뿐이라 어떤 정적 호스팅에도 올릴 수 있습니다. GitHub Pages, Netlify, Cloudflare Pages 모두 무료입니다. 학교 웹서버의 폴더 하나에 올려도 됩니다.
- **데이터**: 모든 내용은 `data/*.js` 파일 3개에 들어 있습니다.
- (선택) 학교 도메인(예: `dorm.OO.ac.kr`)은 호스팅의 Custom domain 설정과 DNS의 CNAME 추가만으로 연결됩니다. 추가 비용은 없습니다.

## (선택) GitHub Pages로 운영 + 버튼 한 번 배포

1. GitHub에 새 저장소(예: `yuhandormitory`, Public)를 만들고 이 폴더의 파일을 모두 올립니다. `Add file` → `Upload files`로 끌어다 놓으면 됩니다.
2. 저장소 → Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`.
   잠시 뒤 `https://student378.github.io/yuhandormitory/`로 접속됩니다.
3. 여기까지만 해도 운영할 수 있습니다. 관리자에서 파일을 내려받아 GitHub 웹에서 `data` 폴더에 업로드하면 됩니다.
4. 더 편하게 하려면 관리자 → **연결 · 백업**에서 토큰을 연결합니다. 그러면 **저장 · 배포** 한 번으로 바로 반영되고, 이미지·첨부 업로드도 관리자에서 됩니다.
   - 토큰 발급: GitHub → Settings → Developer settings → Fine-grained tokens → 이 저장소만 선택 → Contents: **Read and write**
   - 토큰은 GitHub 외 어디에도 전송되지 않고 해당 브라우저에만 보관됩니다. 공용 PC에서는 "토큰 기억하기"를 끄세요.

## 관리자 페이지에서 할 수 있는 일

| 메뉴 | 내용 |
|---|---|
| 대시보드 | 게시물 수·이번 주 식단 등록 현황·노출 중 팝업, 최근 글 바로 수정 |
| 기본 정보 | 대학/사이트 이름, 로고, 대표 색상, 주소·연락처, 하단·상단 링크, 관련 사이트, 메인 게시판 탭 |
| 메뉴 · 페이지 | 대메뉴/하위메뉴 추가·삭제·순서, 종류(일반 페이지·게시판·식단표·일정·외부링크), 페이지 본문 편집기(표·이미지·지도 iframe) |
| 메인 비주얼 | 슬라이드 이미지·문구·버튼 링크 |
| 퀵메뉴 | 아이콘·이름·링크 |
| 팝업 · 알림존 | 기간 지정 레이어 팝업("오늘 하루 열지 않기" 지원), 알림존 배너 |
| 게시판 | 공지사항·입퇴사 공지·소식(갤러리형)·FAQ(아코디언형)·자료실, 상단 고정, 첨부파일, 게시판 추가 |
| 주간식단표 | 주 단위 입력, 엑셀 범위 복사→붙여넣기, 지난주 복사 |
| 생활관 일정 | 일정 등록 → 메인 목록과 월간 달력에 표시 |
| 연결 · 백업 | (선택) GitHub 연결, 전체 백업 내려받기 / 백업 파일로 복원 |

## 파일 구조

```
index.html          공개 홈페이지
admin.html          관리자
assets/
  site.css / site.js     공개 화면 (해시 라우팅: #/m/{메뉴ID})
  admin.css / admin.js   관리자
  icons.js / loader.js   아이콘 세트, 데이터 불러오기 (공용)
data/
  site.js       설정·메뉴·페이지 본문·슬라이드·퀵메뉴·팝업·배너·일정
  posts.js      게시판과 게시물
  meals.js      식단 (날짜별 조식/중식/석식)
uploads/        이미지·첨부파일
manual.html     관리자 사용 매뉴얼 (manual/ 폴더에 화면 캡처)
```

## 참고

- 기본 데이터의 학교명·주소·금액·식단은 모두 **예시**입니다. 관리자에서 실제 내용으로 바꿔 주세요.
- 조회수·댓글·로그인 같은 서버 기능은 없습니다. 유지비 0원을 위해 뺐습니다. 온라인 신청은 학교 포털이나 구글 폼 링크를 메뉴(외부 링크)나 퀵메뉴로 연결하세요.
- 홈페이지 파일은 누구나 볼 수 있으므로 개인정보가 담긴 첨부파일은 올리지 마세요.
